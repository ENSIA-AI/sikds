# Internationalization (i18n)

Locales: `fr` (source), `en`, `ar`. Source string IS the key, no codes like `dashboard.title`.

## Resolution order
`session('locale')` → `cookie('sikds_locale')` → `Accept-Language` → `config('app.locale')`.
Handled by `App\Http\Middleware\SetLocale` (web group). Switching: `GET /change-language/{lang}` (route `changeLanguage`), persists for 1 year.

## Files
- `lang/{fr,en,ar}.json`, translations
- `config/languages.php`, `lang` map + `rtl` list
- `resources/css/rtl.css`, RTL overrides (auto-applied via `<html dir>`)
- `resources/views/layouts/partials/language-switcher.blade.php`, header switcher

## Rules
1. Wrap every user-facing string in `__()` (alt, aria-label, placeholder, flash, validation, email).
2. Variables: `__('Bonjour :name', ['name' => $user->name])`.
3. Plurals: `trans_choice('{0} Aucun|{1} 1 document|[2,*] :count documents', $n, ['count' => $n])`.
4. JS strings: pass via `@json(__('...'))` from blade, never hardcode FR in `.js`.
5. RTL: prefer Tailwind logical utilities (`ms-*`, `me-*`, `ps-*`, `pe-*`, `start-*`, `end-*`) over `ml-*`/`left-*`.

## Commands
| Command | Purpose |
|---|---|
| `composer i18n:scan` | Add new `__()` keys to all 3 JSON files |
| `composer i18n:lint` | Fail on missing translations; warn on hardcoded blade text |
| `composer i18n:check` | Both, in `--check` mode (CI) |
| `php artisan i18n:lint --strict` | Also fail on hardcoded blade text |
| `php artisan i18n:lint --paths=documents` | Narrow blade scan |

## Adding a feature
1. Write code with `__('Texte')`.
2. `composer i18n:scan` → keys land in all JSON files.
3. Fill EN + AR values.
4. Commit code + JSON together. CI ([.github/workflows/lint.yml](../.github/workflows/lint.yml)) enforces.

## Translation Key Convention
This project uses : the French source text IS the translation key.
- Wrap every hardcoded string with `__('French text here')`.
- For strings with variables, use the `:placeholder` syntax: `__('Message avec :name', ['name' => $var])`. Never use PHP interpolation `{$name}` inside `__()` — it runs before Laravel sees the string and breaks lookup.
- JS strings must NOT call `__()` directly. Add the key to the `window.i18n` object in [resources/views/layouts/app.blade.php](../resources/views/layouts/app.blade.php) (just above `</body>`) and read it in JS as `window.i18n.<key>`.
- Lang files live at [lang/](../lang/) (Laravel 9+ default), not `resources/lang/`.
- Carbon dates: always pass the active locale — `->locale(app()->getLocale())`. Never hardcode `->locale('fr')`.
- Run `grep -rn "locale('fr')" resources/ app/` before each PR to catch regressions.
